FAQ

Before you install.

Is this an official Codex plugin?

No. Codex Quota Header is not affiliated with OpenAI. It mounts UI via local Chrome DevTools Protocol (CDP). It does not patch the installed package, but relies on unofficial DOM structure.

Why is the five-hour window missing?

It is shown only when the account response contains a 300-minute window. The tool does not infer entitlements from Pro or other plan names.

Can it measure local, Dots or per-device USD spending?

No. Account rate limits are not token or USD billing. Usage on another device can affect the same account's remaining quota.

What about macOS, Linux or other Codex versions?

Desktop support is currently Windows 10 / 11 only. Linux CI tests portable logic and packaging, not Linux desktop compatibility. Consult the facts page for recorded versions and limitations.

Is it free? What about commercial use or modifications?

Ordinary end-user installation, including workplace quota display, needs no notice. Before commercial use or modified distribution to third parties, submit one Usage notice Issue under the full license. No fee, approval or reply is required.
