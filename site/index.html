再挂载顶栏。

需要 Windows 10 / 11、PowerShell 5.1+、Node.js 22+、Python 3.10+，以及已登录的 Microsoft Store Codex 桌面端和支持 app-server 的原生 codex.exe。

无第三方 npm / pip 依赖。已记录实机版本：Codex 26.1007.9446.0、Node 24、Python 3.12（2026-10-15）。其他桌面版本尚未验证。

git clone https://github.com/vence15008-ai/codex-quota-header-public.git

检查环境

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 -Action Doctor

ExecutionPolicy 参数只作用于本进程；请遵守组织的设备管理策略。

包括退出托盘进程。工具不会强制关闭现有 Codex，也不会自动启用开机启动。

FAQ

安装前，你可能想知道。

它是 Codex 官方插件吗？

不是。Codex Quota Header 与 OpenAI 无关联，通过本机 Chrome DevTools Protocol（CDP）挂载 UI。它没有修改 Codex 安装包，但依赖非官方 DOM 结构。

为什么我的 5H 额度没有显示？

只有接口返回 300 分钟的额度窗口才会显示。工具不按 Pro 等套餐名称推断权益，也不补造接口没有给出的数据。

能看本机、Dots 或多个设备分别花了多少美元吗？

不能。这里只读取账号限额，并非 token / USD 计费或逐设备用量追踪。相同账号在别处的消耗也可能影响剩余额度。

macOS、Linux 或所有 Codex 版本都能用吗？

当前桌面端仅支持 Windows 10 / 11。Linux CI 只覆盖可移植逻辑和打包，不代表支持 Linux 桌面。已验证版本及边界请看项目事实页。

免费吗？商用或者修改后发布要做什么？

普通安装使用，包括工作场景的额度显示，无需通知。商用或修改后向第三方分发前，按完整许可证提交一次 Usage notice Issue 即可，无费用、审批或等待回复。
